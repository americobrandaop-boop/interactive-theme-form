# Interactive Theme Form

Formulário interativo desenvolvido durante meus estudos de HTML, CSS e JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Sobre o projeto

Este projeto consiste em um formulário interativo com alteração de tema utilizando JavaScript.

A proposta foi utilizar JavaScript para modificar elementos da página de acordo com a interação do usuário, tornando o formulário mais dinâmico.

## Objetivos

- Praticar HTML
- Trabalhar estilização com CSS
- Utilizar JavaScript para interações
- Manipular elementos da página
- Criar uma interface mais dinâmica

## Projeto online

Acesse o projeto pelo GitHub Pages:

## Aprendizados

Durante o desenvolvimento, pratiquei principalmente manipulação do DOM, eventos em JavaScript, utilização de atributos `data-*`, alteração de estilos e integração entre HTML, CSS e JavaScript.
